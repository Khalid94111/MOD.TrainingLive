📌 ما الذي يتغيّر

إضافة: Course Info Bar ثابت (sticky) أسفل الـ status pipeline في صفحة Session Detail وصفحة Casual Course Detail. يعرض المعلومات المرجعية دائماً أثناء تصفّح الـ user للأقسام.

إضافة: Variance indicator حيّ (live) داخل dialogs الـ Add Quote و Pick Winner يقارن السعر المُدخل بالتكلفة المعتمدة فوراً.

المعلومات في الـ bar: اسم الدورة، المدة، عدد المرشحين، التكلفة المعتمدة الإجمالية، للوحدة (إن أمكن).

📋 ملخّص التغييرات

1️⃣
Course Info Bar ثابت (sticky) — يظهر تحت status pipeline في:
  • صفحة Session Detail (PAGE D من Phase 4C-α)
  • صفحة Casual Course Detail (Phase 4B-α/β)
2️⃣
Variance Indicator — في عمود جديد بجدول العروض + داخل Add/Edit Quote dialog + Pick Winner dialog
  • أخضر: السعر أقل من المعتمد (وفر)
  • رمادي: مطابق تماماً
  • أصفر: أعلى بحدود معقولة (~10%)
  • أحمر: تجاوز كبير (>10%)
3️⃣
إعادة استخدام — مكوّن واحد CourseInfoBarComponent يأخذ inputs polymorphic (course أو session) ويعمل في كلا السياقين.
4️⃣
اختلاف Casual vs Session — Casual Course Info Bar يعرض حقل إضافي "سيناريو التمويل" (1/2/3) لأنه خاص بالدورات العرضية. Session Info Bar لا يعرضه.
