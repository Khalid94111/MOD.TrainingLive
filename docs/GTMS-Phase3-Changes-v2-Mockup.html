🆕 CHG-07 — حسابات يومية + لكل مرشح + أيام السفر

بعض البنود (كبدل السفر) يومية — مبلغ الرتبة × (أيام الدورة + يوم سفر + يوم عودة) × عدد المرشحين.

مثال: بدل سفر عقيد = 50 ر.ع/يوم، دورة 5 أيام، +1 قبل +1 بعد، 1 مرشح
effectiveDays = 5 + 1 + 1 = 7 يوم
subtotal = 50 × 7 × 1 = 350 ر.ع
✗ ✗ ثابت (رسوم دورة)
✗ ✓ لكل مرشح (ملابس)
✓ ✗ يومي (قاعة)
✓ ✓ يومي + لكل مرشح (سفر/إقامة)
✈️ الأيام الإضافية تُضبط لكل بند مالي على حدة: بدل السفر = +1/+1، إيجار قاعة = 0/0، بدل ملابس = لا يهم (ليس يومي).

❓ فحوصات نهائية قبل البرمجة

  1. تأكيد: تعديل Staff للمبلغ في Plan Review يؤثر على بند الخطة فقط، مش الإعدادات العامة؟
  2. الأيام: هل يمكن لـ Staff تعديل عدد الأيام في البند المالي (مثلاً الدورة 14 يوم لكن السفر 10 أيام فقط)؟
  3. مرشح جديد: لو UTM أضاف مرشح بعد الإعادة، يتم إنشاء صف رتبة جديد تلقائياً بالمبلغ الافتراضي؟
  4. حظر الاعتماد: TD/TH لا يقدرا يعتمدا لو فيه أي PlanItem.IsReturned أو Nomination.IsReturned = true (Staff يشوف banner أحمر)؟

👥 المبالغ حسب الرتبة — Rank Overrides CHG-03

المبلغ لكل رتبة لكل يوم لكل مرشح (لأن البند يومي + لكل مرشح). إذا لم تُضف الرتبة، يُستخدم المبلغ الافتراضي (50 ر.ع/يوم).
الرتبة المبلغ/يوم/مرشح (ر.ع) إجراءات
عقيد (Colonel) 100
ملازم أول (First Lieutenant) 50
جندي أول (Private First Class) 30
🧮 مثال الحساب: دورة 5 أيام + يوم سفر قبل + يوم سفر بعد = 7 أيام، 3 مرشحين
عقيد: 100 × (5 + 1 + 1) × 1 = 700 ر.ع
ملازم أول: 50 × 7 × 1 = 350 ر.ع
جندي أول: 30 × 7 × 1 = 210 ر.ع
المجموع: 1,260 ر.ع
✈️ الأيام الإضافية: 1 قبل (للسفر) + 1 بعد (للعودة) = يُضافا تلقائياً لكل البنود المالية اليومية

🧩 مصفوفة حساب البنود المالية (CHG-07) — مع الأيام الإضافية

🗓️ يومي؟ 👤 لكل مرشح؟ مثال الصيغة
✗✗ رسوم الدورة (مبلغ ثابت) = amount
✗✓ بدل ملابس = amount × nominees
✓✗ إيجار قاعة = amount × (days + before + after)
✓✓ بدل السفر / إقامة = rate × (days + before + after) × nominees
✈️ الأيام الإضافية (ExtraDaysBefore / ExtraDaysAfter)
بعض البنود مثل بدل السفر تُغطي أيام إضافية قبل وبعد الدورة لأن المرشح يحتاج يوم للسفر ويوم للعودة.
مثال: دورة 5 أيام + 1 قبل + 1 بعد = 7 أيام مدفوعة.
تُضبط هذه الأيام لكل بند مالي على حدة (0 للبنود التي لا تحتاج أيام سفر).
